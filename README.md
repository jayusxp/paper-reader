# 阅研 · 双语研究工作台 v2

PDF / DOCX / PPTX / XLSX / EPUB / TXT / Markdown / HTML / CSV 的导入、段落对齐翻译与批注阅读。已发布到原有私有站点，保留原项目身份和访问范围。

## 应用结构

- `public/reader/`：本地优先的阅读客户端，原版 PDF 通过 PDF.js 5.4.624 展示。
- `public/reader/model.js`：稳定段落 ID、PDF 坐标、翻译批次、导出、备份校验。
- `public/reader/importers.js`：文本及 OpenXML / EPUB 格式解析，fflate 0.8.2。
- `app/api/import/`：公开 HTTPS 链接导入，arXiv abs 转 PDF，重定向逐跳验证。
- `app/api/translate/`：OpenAI 兼容服务转发，严格验证段落 ID，不依赖模型 CORS。
- `app/api/cloud/`：登录用户隔离的 R2 快照，使用条件写入防止覆盖他端修改。
- `app/api/me/`：读取平台登录身份。
- `lib/network.mjs`：HTTPS、公网域名/IP、DNS、响应大小限制。
- `lib/api.ts`：API 登录及 Origin 验证、统一错误响应。

## 核心工作流

1. 导入文档或公开链接，解析为带唯一 ID 的原文段落；PDF 额外保存对应坐标。
2. PDF 默认显示原始页面，原文不可编辑；其他文档采用独立自然排布的原文列和译文列，不通过共享行高改变原文结构。
3. PDF 原版视图保留图表/版面，点击段落译文定位原文，支持双向滚动联动。
4. 配置模型地址、模型名称、API Key、术语表；按段、本页或剩余全文翻译。
5. 翻译按最多 6 段分批，校验输出 ID；成功立即保存，支持暂停和恢复未完成段落。
6. 高亮、标签笔记、段落定位、书签、全文检索；可编辑译文并标记已校对。
7. 手动云备份或 JSON 完整备份，用于跨设备恢复；Markdown / 双栏 HTML 用于分享和打印。

首页示例使用用户提供的 77 页论文，预置首页 11 个对应块的译文。预置译文不代表实际 API 联调成功。

## 模型配置与数据边界

- 接口为 `{base}/chat/completions`，JSON 返回的每个段落需保留输入 ID。
- Key 仅驻留当前页面内存，发往本站代理及用户指定的模型服务，不持久化。
- 用户导入文件默认保存在浏览器 IndexedDB。云备份仅在用户点击后执行。
- 云存储使用 Sites 托管登录身份及 BUCKET R2 绑定。云备份为手动快照，不是自动同步。
- 文件上传最大 20 MB，备份 32 MB，PDF 最多 1000 页。ZIP 解压文本大小和文件数量均有限制。
- 私有地址、非 HTTPS、IP 字面量与不安全重定向被拒绝。公网 DNS 检查不是正式渗透测试的替代品。

## 原文结构修正

PDF 默认采用原版对照，纯原文模式也使用原始 PDF，未修改上传文件字节。非 PDF 文档不再每 14 段分页，不按字数拆分自然段；HTML / DOCX 标题级别和表格信息保留。旧文档重新解析时保留原数据备份，并迁移可以精确匹配的译文和笔记。非 PDF 字体、页边距及复杂版式仍不等同原生 Office 渲染。

## 译文结构修正

PDF 译文按连续文章呈现，沿用原文页内段落顺序与标题层级，隐藏逐段卡片标签，悬停或键盘聚焦时才显示操作。标题字号及段落缩进参考源 PDF 文本区域；译文长度自然流动，不承诺中文文字与英文逐行等高。非 PDF 译文同样采用自然文章排版。翻译提示明确要求不合并、拆分或重排源段落。

## PDF 原图复用

自动分析 PDF 绘图与图注位置，识别普通图片及有图注的矢量图，在译文相应位置直接展示原页面图像区域。图内文字默认不翻译，不重绘；图注作为正文块独立翻译。图片内文本从自动翻译任务中排除，已有数据不删除。无图注的复杂矢量图可能漏识别，左侧“框选原图”支持手动补充；可移除错误展示。图片保持原裁剪区域像素比例，可点击放大和定位。

在测试论文的全部 77 页中识别到 9 个带图注的图像区域；对其中 4 个代表性原图裁剪进行了本地视觉核验，包括矢量分类图。浏览器完整交互仍未验收。此功能当前针对 PDF；非 PDF 格式及 HTML 导出的图片复用尚未实现。
